02 / FILE

导入额度快照

选择 Tokscale 的 usage JSON，并标记实际采集时间。文件中的 Token 消耗不会被当作额度。

03 / BROWSER BRIDGE

Claude · Grok · Gemini 自动采集

安装并配对一次，之后点击「同步额度」即在后台读取官方用量页。网页版作为这些平台的主来源，共享额度只显示一次。

一次性安装步骤

在 Edge 扩展管理页打开开发人员模式，选择「加载解压缩的扩展」，选中项目里的 extension 文件夹。然后点击扩展图标，粘贴配对码并开启。

仅授予 Claude、Grok、Gemini 和 127.0.0.1 的访问权限，不读取 Cookie、密码或对话。采集会打开并关闭专用后台标签页。

04 / ON DEMAND

你点击，后台更新。

点击「同步额度」会同时请求本地 Codex 与浏览器额度。网页采集使用不激活的临时标签，完成后关闭，保持当前页面不变。

没有定时采集。超过 15 分钟或经过重置时间的读数会被标记，下一次点击后重新核对。
